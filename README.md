# Supply Chain Data Analysis

This project explores a supply chain dataset using exploratory data analysis (EDA). 
The goal is to understand patterns in product sales, pricing, stock levels, and shipping operations.

## Dataset
The dataset contains information about products, pricing, shipping carriers, revenue, and stock levels within a supply chain system.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Steps

1. Data loading and inspection
2. Data cleaning
3. Product sales analysis
4. Shipping carrier distribution
5. Price vs revenue analysis
6. Stock level distribution
7. Correlation analysis

## Key Insights

- Some product categories dominate sales.
- Shipping carriers show uneven usage distribution.
- Higher priced products tend to generate higher revenue.
- Stock levels vary significantly between products.

## Visualization Examples

The project includes multiple visualizations such as:

- Product sales distribution
- Shipping carrier pie chart
- Price vs revenue scatter plot
- Correlation heatmap
